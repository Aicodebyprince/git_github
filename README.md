# Git Workflow Simulator & Git Masterclass

A premium, interactive, visually stunning developer simulation game and masterclass that teaches professional Git and GitHub workflows used by top-tier software teams.

![Git Workflow Simulator](public/preview.png)

## 🌟 Highlights

- **Linear & GitKraken Inspired UI**: Ultra-clean dark theme with glowing neon indicators, glassmorphism, and responsive design.
- **3 Straight Parallel Railway Tracks**: Live deterministic SVG Git Graph with clear vertical rails for `main`, `login-feature`, and `register-feature`, smooth branching and merging arcs, and synchronized commit rows.
- **ShopFlow Auth Engineering Scenario**: 3 developers (Alex Rivera - Backend, Sarah Chen - Frontend, Mike Kowalski - Full-Stack) collaborating under enterprise branch protection guardrails.
- **Real-World Engineering Challenges**:
  - Feature branch isolation
  - Code review & Pull Request protocols
  - Safe branch integration & release merges
  - Upstream synchronization with `git rebase main`
  - History hygiene with `Squash Merge` (8 messy WIP commits → 1 clean production commit)
- **Immediate Audio-Visual Feedback**: Synthesized Web Audio chimes, tactile clicks, and warning alerts explaining *why dangerous actions (like direct pushes to main) break production*.
- **Repository Health & Guardrails**: Live circular health gauge tracking policy compliance and preventing regressions.
- **Celebration Finale**: 100% health certificate and confetti explosion upon completing the mission.
- **Full Masterclass Deck**: 23 interactive slides covering Git fundamentals from file chaos to GitHub Actions.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Aicodebyprince/git_github.git

# Navigate to project directory
cd git_github

# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
